# 🔳 PragyanAI QR Code Generator & Decoder

A complete QR Code Generator and Decoder project built using Python, Streamlit, FastAPI, HTML, CSS, JavaScript, Pillow and ZXing-C++.

This project demonstrates both a beginner-friendly Streamlit application and an advanced Frontend + Backend REST API architecture.

---

# 🚀 Project Overview

The application provides two major capabilities:

1. Generate QR Codes
2. Decode QR Codes

Users can enter a URL or text and generate a QR Code.

Users can also upload an existing QR Code image and decode the information stored inside it.
